# @jamzo/catalog-engine

**Pure** restaurant and menu rules (DECISIONS D-38, D-37): is a branch open now (business hours, manual
close, pause), is a product orderable now (status, sold-out switch and windows, stock, schedules,
variants), product structure rules (variants, add-on groups, food-type consistency, pure veg). Time and
timezone are inputs; nothing here reads the clock or the database. Design: [docs/RESTAURANTS.md](../../docs/RESTAURANTS.md).
