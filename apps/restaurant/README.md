# Restaurant app (`@jamzo/restaurant`)

Expo (React Native, **JavaScript**) app for restaurant owners/managers/staff — Android + iOS.

- Identifiers (proposed): `in.jamzo.restaurant` · scheme `jamzo-restaurant://`
- Own version, icon (charcoal), splash, push configuration (loud new-order channel), EAS project, release tag `restaurant@x.y.z`
- Orders, menu/availability, pause/busy mode, earnings and settlements for the user's own restaurant only
