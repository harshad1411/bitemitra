JAMZO LOGO KIT v7 (latest)
==========================
Every logo comes in BOTH versions (without and with tagline), and every file is in BOTH SVG and PNG.

FOLDERS
1-logo-without-tagline/   Main logo. Use this by default everywhere.
2-logo-with-tagline/      Same logos with "GOOD FOOD. CLOSER." for posters and banners.
3-icon-mark/              The J symbol alone.
4-app-icons/              App Store, Play Store, Android adaptive, favicons, social profile.

VARIANTS (in folders 1 and 2)
on-light          navy logo, transparent background (for light backgrounds)
on-dark           white logo, transparent background (for dark backgrounds)
navy-background   white logo on a navy box
white-background  navy logo on a cool-white box
mono-navy         one colour navy (stamps, 1-colour printing)
mono-white        one colour white (printing on dark bags, t-shirts)

COLOURS  Midnight navy #1B2250 | Turmeric #F2B21B | Leaf green #2F8F6B | Cool white #F4F5FB
FONT     Poppins (SIL Open Font License, free for commercial use). SVGs need no font install.

QUICK GUIDE
- App icon (Expo/App Store): 4-app-icons/png/app-icon-1024.png
- Play Store listing:        4-app-icons/png/play-store-icon-512.png
- Website header:            1-logo-without-tagline/svg/jamzo-logo-on-light.svg
- Instagram/WhatsApp DP:     4-app-icons/png/social-profile-800.png
- Printing:                  send the SVG files to the printer
