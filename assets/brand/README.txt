BITEMITRA LOGO KIT (final)
==========================
Every logo is in BOTH SVG and PNG.

FOLDERS
1-horizontal/                 Main logo: icon + BiteMitra side by side. Use this by default.
1-horizontal-with-tagline/    Same, with "Good Food. Closer to You." (posters, website hero, ads)
2-vertical/                   Icon on top, name below. For square spaces (splash screen, bag front, posts).
2-vertical-with-tagline/      Same, with tagline.
3-icon-mark/                  The bitten-B bowl icon alone (with and without the bite sparkles).
4-app-icons/                  App Store, Play Store, Android adaptive, favicons, social profile.

VARIANTS (in folders 1 and 2)
on-light            charcoal + orange text, transparent background (for white/light backgrounds)
on-dark             white + orange text, transparent background (for dark backgrounds/photos)
white-background    on a solid white box
orange-background   all-white logo on a solid orange box

COLOURS   Orange #F37321 | Charcoal #25282B | White #FFFFFF | Leaf green #3E9B37
FONTS     Logo: Nunito Black. Tagline: Poppins Regular.
          Both SIL Open Font License, free for commercial use. SVGs need no font install.

QUICK GUIDE
- App icon (Expo / App Store):  4-app-icons/png/app-icon-1024.png
- Play Store listing:           4-app-icons/png/play-store-icon-512.png
- Android adaptive icon:        4-app-icons/png/android-adaptive-foreground-432.png + background
- Website header:               1-horizontal/svg/bitemitra-horizontal-on-light.svg
- Website favicon:              4-app-icons/png/favicon-32.png, favicon-192.png, apple-touch-icon-180.png
- Splash screen:                2-vertical-with-tagline/svg/bitemitra-vertical-orange-background-tagline.svg
- Instagram / WhatsApp DP:      4-app-icons/png/social-profile-800.png
- Printing (bags, t-shirts):    send the SVG files to the printer

BEFORE PRINTING OR FILING A TRADEMARK
Run the IP India trademark search for "BiteMitra" and have a designer do a final polish.
